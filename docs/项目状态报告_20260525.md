## 一、项目概览

**DevTrace** 是一个 AI 辅助研发流程的项目记忆与智能体调度平台，核心定位是让多个 AI 工具（Claude Code、Codex、GPT）协同作战。用户在聊天窗口发指令，系统自动调度合适的 AI 去执行任务，并沉淀知识。

**技术栈：**
- 后端：FastAPI + SQLAlchemy 2.0 + PostgreSQL 15 + Alembic + JWT
- 前端：Vue 3 + TypeScript + Element Plus + Pinia + Axios
- 部署：Docker Compose（PostgreSQL + 后端 + 前端/Nginx）

**默认账号：** admin / admin123
